# 主動目標資訊與同頁歷史回放

依 0908 APP 組週報第 9、12 頁及使用者後續說明實作。

## 介面行為

- 總覽右側在一般狀態顯示節點資訊；15 秒內的無人機偵測自動切換成目標資訊，並在其他頁面顯示可返回總覽的主動提示。
- 偵測提示不需要先點選目標。聲音事件只有回報節點座標時，不把該座標畫成無人機位置。
- 有有效目標定位時顯示無人機圖示；有據點設定時畫出警戒圈。右側顯示距離、接近狀態、預估進入警戒區及預估抵達據點範圍。
- 新目標首次觀測於警戒區內，或同一目標明確離區後再次進區，使用原生 dialog 主動彈出警告。按確認或 Escape 確認當則警告；多則排隊。持續區內更新不重複彈出。重新載入頁面會重新判斷目前目標。
- 定位誤差跨越警戒邊界時顯示不確定，不當作確定進區或重新武裝警告。
- 歷史頁左側選事件、右側直接開始軌跡回放，提供播放／暫停、重播、1/4/8/16 倍速與時間軸。切換頁面或背景分頁會暫停。
- 回放依 measurement_time_ms 排序，依原始觀測時間推進。缺少完整時間時明示以觀測順序回放。只顯示已記錄點，不插值、不預測。Google Maps 不可用時顯示相對座標圖。
- 每次最多取得 500 個點，達上限明示可能不是完整軌跡。快速切換事件時忽略過期查詢結果。

## 據點設定與資料契約

「據點與警戒區設定」可輸入名稱、經緯度、警戒半徑、抵達據點範圍。抵達範圍必須小於等於警戒半徑。這是此瀏覽器的設定（localStorage sound-dashboard-site-v1），不會改動手機節點固定位置，也未新增共用 Site 資料表。授權碼不存入此設定。

GET /event-groups/{group_id}/tracks 使用資料庫 target_track_points.group_id 查詢明確關聯，即使群組不在最近事件快照也能找到。參數驗證 UUID、參數化 SQL、最多 100 條軌跡；資料庫錯誤回 503，不宣稱沒有資料。多條關聯軌跡讓使用者選擇。

軌跡支援後端實際回傳的 recent_points 與既有 points，排除 rejected_as_outlier。事件詳情也提供「播放事件軌跡」入口。

## 警戒與 ETA 條件

定位必須開啟、觀測在 15 秒內，來源是 localization_result，定位方法符合支援的 TDOA 方法，至少兩節點且有非負定位誤差。節點 GPS 與區域中心不能觸發警戒。

ETA 另需開啟 experimental motion。後端從最近 20 個接受的聲源定位點計算既有 constant-velocity estimate，傳回 approach_motion；僅 valid、high quality 且來源時間與目前定位相同時才評估。採直線與圓形交點，預測上限 300 秒，非 distance/speed 捷徑。未相交或品質不足不顯示 ETA。兩種 ETA 分別對應警戒半徑及較小的據點抵達範圍，並非飛到中心點的保證。

本次不自動開啟 staging 的定位或 motion 旗標、不修改 production、不將模擬資料寫入雲端。現有 staging 若沒有有效聲源定位，會先提供主動偵測資訊，警戒與 ETA 顯示資料不足。瀏覽器警告須保持 Dashboard 開啟，未實作 OS 背景推播或手機通知。

## 驗證

Node 測試涵蓋進區幾何、擦身而過、遠離、過期／未來觀測、來源限制、邊界不確定、重複更新與重新進區、時間排序與回放。Python 測試涵蓋 SQL 關聯去重、不寫入、參數隔離、錯誤狀態，以及 motion 品質與來源過濾。

本機隔離 fixture 瀏覽器驗證已確認主動彈窗、確認警告、右側同頁動畫、倍速、暫停、時間軸結束點與相對座標圖示。這些是開發測試，並非實機飛行驗證。
