# 地圖設定與模擬工作區（2026-09-13）

監控總覽的據點設定採用與固定節點相同的 Google 地圖選點方式：點擊選擇、拖曳微調，再儲存。據點與警戒／抵達半徑存於目前瀏覽器；固定節點位置則由既有 `/device-locations` API 儲存並同步。

## 即時地圖

- 固定位置獨立讀取並與裝置狀態合併。節點離線或尚未回報也持續顯示，不能因此被算成上線。
- 同一事件中，最近 15 秒的 Drone 回報節點會顯示脈動；兩點連線、三個以上不共線節點形成凸包。只採明確事件群組成員，不拼接無關事件。
- 線與範圍表示參與偵測的節點，不代表無人機定位或誤差範圍。目標圖示與真實警戒／ETA 仍需符合既有定位來源、時效、品質與功能旗標要求。
- 清除固定設定立即移除快取；尚未回報的節點允許 API 回覆 `device: null`。舊快照不能覆蓋較新的位置設定。
- 歷史事件／軌跡於右側地圖原地播放，關閉會停止動畫、取消未完成載入並清除圖形。

## 展示操作

1. 進入「模擬工作區」。可直接選擇「快速展示」並按「載入展示」，或從空白場景自行佈置。
2. 用「點圖新增節點」、「點圖設定據點」放置位置；每個節點可個別輸入 20–5000 公尺偵測半徑，也可移動、刪除、切換上線／離線及啟用偵測。
3. 選聲音類型、速度、航向及出現位置，按「建立事件並主動顯示」。也可勾選尚未定位，展示只有聲音而無軌跡／ETA 的情境。
4. 依序點圖加入的是模擬無人機的真實飛行路徑。開始／暫停、單步前進或切換倍速後，紫色實線顯示真實路徑，藍色虛線顯示節點佈置推估出的路徑。
5. 無人機進入節點偵測半徑才算該節點同時偵測。單節點顯示偵測圈；兩節點把兩點之間視為可能聲源；三個以上用偵測節點凸包顯示可能聲源區域。至少兩個節點同時偵測才產生推估位置。
6. 觀察右側的同時偵測數、可能聲源區域、推估誤差、ETA 及進區警告；也可模擬失聯、恢復、停止或變更速度／航向。
7. 點選模擬歷史事件，原地同步播放真實與推估軌跡；支援暫停、重播與時間軸。

快速情境包含一般監控、單／雙／三節點、接近、飛越、遠離、直接進區、多目標、未定位、失聯、節點離線及非無人機聲音。模擬最多 12 節點、20 目標，每目標最多保留 600 點。

## 隔離與限制

模擬使用自己的狀態、地圖、圖形與計時器，不呼叫業務 API、不使用 WebSocket、不寫入 localStorage 或共用事件資料；Google 地圖底圖仍由 Google 載入。離開工作區暫停播放並關閉模擬警告。未載入 Google 地圖時，改用可點擊的相對座標圖。

模擬推估位置以偵測半徑內節點及相對訊號權重計算，用來比較節點佈置；它不是實際 TDOA 解算結果。模擬 ETA 是指定速度與目前方向的展示值。真實定位與 ETA 仍需要有效的時間同步、TDOA／定位和運動資料及實地驗證。

播放時保留 Google Maps 圖層物件，只更新座標、路徑與樣式；右側動態資訊降頻更新，避免每一影格刪除並重建整個畫面造成閃爍。

## 驗證

Python 完整套件、JavaScript 回歸套件及瀏覽器操作驗證涵蓋：固定節點合併、群組成員與時效、幾何圖形清理、位置同步競爭、據點介面、模擬隔離／進區／ETA／回放，以及歷史回放關閉。

未改動資料庫結構、手機模型、上傳協定或 production 環境。
