# Dashboard 與 APK 視覺統一

Dashboard 的 `static/dashboard_apk_theme.css` 在既有結構樣式後載入，依現有 Flutter APK 的 `lib/ui/theme/app_theme.dart`、`section_card.dart`、`status_badge.dart` 與 `monitor_primary_action.dart` 建立共同視覺。

## 對應規則

| 元素 | APK 與 Dashboard 共用規則 |
| --- | --- |
| 背景 | `#0B1220`；側欄 `#08101C` |
| 卡片 | `#142033`、16 px 圓角、`#27384F` 細邊框，無常駐大陰影 |
| 次層容器 | `#101A2A`／`#1A2940`，避免過多不同色塊 |
| 主操作及選中導覽 | `#143B3A` 背景、`#99F6E4` 文字、`#5EEAD4` 焦點與邊框 |
| 文字 | 主文字 `#E5ECF5`、次文字 `#9EACC0`；內文 14 px、說明 12 px、區塊標題 16 px |
| 按鈕／輸入 | 12 px 圓角；桌面一般按鈕至少 40 px、手機至少 44 px、主要監聽操作 48 px |
| 目標／警戒 | 橘色 `#FB923C` 表示目標、粉紅 `#FB7185` 表示警告；以文字、邊框和圖示共同呈現 |
| 模擬識別 | Lavender `#C4B5FD`，與真實監控狀態區分 |

## 操作與版面

- 監控地圖、節點列表、事件資料、據點選點表單及歷史動畫共用相同的容器與控制樣式。
- 據點設定使用與固定節點相同的地圖／表單並排呈現；窄螢幕改為上下排列。
- 目標資訊用橘色上邊框強調；進區警告用原生 dialog、清楚的確認按鈕及有限大小的捲動內容。
- 1920 px 與 1366 px 保持側欄和寬畫面工作区；1024 px 壓縮導覽寬度，事件明細移到清單下方；手機保留可横向捲動導覽和至少 44 px 觸控按鈕。
- 鍵盤操作保留高對比 3 px 外框；遵循減少動畫的系統設定。
- 沒有加入新的字型、圖示字型、遠端資產或主題切換依賴。地圖服務本身的控制項維持原樣。

本檔只調整外觀，不改 API、節點資料、告警判斷或模擬狀態。功能與完整瀏覽器驗證由整合版本執行。
