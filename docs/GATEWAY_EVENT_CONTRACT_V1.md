# Gateway Event Contract v1

This contract defines the backend ingestion boundary for Raspberry Pi / Wi-SUN gateways.

## Goal

All transports normalize into the existing backend event path:

```
Wi-SUN / sensor
    -> Raspberry Pi gateway
    -> HTTP or MQTT adapter
    -> GatewayEventV1
    -> normalize_gateway_event()
    -> SoundEvent
    -> persistence / dedup
    -> Fusion / Tracking
    -> Dashboard WebSocket
```

The transport must not own persistence, Fusion, Tracking or Dashboard logic.

## Payload

Required:

- `schema_version`: `gateway.event.v1`
- `gateway_id`
- `node_id`
- `event_id`
- `detected_at_ms`
- `label`

Recommended:

- `sequence`
- `gateway_received_at_ms`
- `confidence`
- `latitude`
- `longitude`
- `gps_accuracy_m`
- `trace_id`

Optional:

- `classification`: must match the backend classification schema when supplied.
- `audio_ref`: reference only; raw audio bytes are not accepted by this event contract.
- `metadata`: transport/vendor metadata. It is not persisted by the v1 normalizer.

## Idempotency

`event_id` is the authoritative backend idempotency key. Gateway retries must reuse the same `event_id`.

`sequence` is for ordering and diagnostics; it must not replace `event_id` as the deduplication key.

## Time semantics

- `detected_at_ms`: event occurrence time at the sensing/inference side.
- `gateway_received_at_ms`: when the gateway received the event.
- `gateway_normalized_at`: generated by the backend adapter.
- `backend_received_at`: generated by the existing backend event path.

These fields allow the transport and backend portions of end-to-end latency to be separated.

## HTTP adapter

`POST /api/gateway/events`

The route is disabled unless:

```
GATEWAY_EVENT_V1_ENABLED=true
```

Authentication continues to use the existing `x-upload-token` behavior.

## MQTT adapter

MQTT is intentionally not coupled to the domain pipeline. A future MQTT subscriber should:

1. Authenticate/authorize the broker connection.
2. Parse the message into `GatewayEventV1`.
3. Call `normalize_gateway_event()`.
4. Send the normalized event through the same internal ingestion path as HTTP.
5. Ack the MQTT message only according to the chosen broker/QoS retry contract.

Suggested topic shape (not frozen):

```
uav/v1/gateways/{gateway_id}/nodes/{node_id}/events
```

Broker URL, QoS, retained-message policy and retry/ack semantics remain vendor-integration decisions and are not frozen by this document.

## Safety

The v1 route is feature-gated and off by default. No database schema, Fusion/Tracking algorithm, production deployment, Render configuration or PostgreSQL pool setting is changed by introducing this contract.
